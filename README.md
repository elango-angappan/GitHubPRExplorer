# GitHub PR File Explorer

A Chrome extension that enhances your GitHub Pull Request workflow with improved file visibility, tracking, and convenient features.

## Features

- **PR File Tracking**: Easily see which files you've already viewed in a PR
- **Mark All Files**: Quickly mark all visible files as viewed/unviewed with a toggle
- **File Counts**: View at-a-glance counts of how many files are visible and how many have been viewed
- **PR Metadata**: See PR title, author, and number in the extension popup
- **Reload Action**: Reload the PR page with a single click
- **Modern UI**: Clean, intuitive interface that adapts to light/dark mode

## How to Use

1. Navigate to a GitHub Pull Request
2. Click the extension icon to open the popup
3. View PR information and file counts at a glance
4. Use the toggles to mark all files as viewed or unviewed
5. Use the reload button to refresh the PR page

## Privacy

This extension only operates on GitHub Pull Request pages and does not collect or transmit any user data.
